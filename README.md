# Bondinho da Leitura

Catálogo web responsivo desenvolvido como projeto acadêmico
da disciplina de Projeto de Software.

## Objetivo

Facilitar a descoberta de livros e o acesso a informações
sobre os serviços e as atividades culturais do Bondinho da
Leitura, biblioteca pública localizada em Curitiba (PR).

## Tecnologias

- Python 3.14
- Flask
- HTML5
- CSS3
- Jinja2
- PostgreSQL 18
- Psycopg 3

## Escopo do MVP

- Pesquisa de livros por título ou autor.
- Exibição de informações bibliográficas.
- Consulta aos serviços da biblioteca.
- Consulta à programação cultural.

O MVP não contempla contas de usuários, empréstimos,
reservas ou painel administrativo.
